# 后续功能路线图

本文件只记录**尚未实现**的计划，不再承担完成记录。已完成能力与验收边界见 [SKILL.md](../../../skills/sanmu-doc2md/SKILL.md) 和 [历史研究验证](../../../examples/sanmu-doc2md/RESEARCH-VALIDATION.md)。

## 近期

- **扫描版跨页续表拼接**：识别续表头、去重表头并在同一逻辑表内合并。当前装配按页独立输出，不做跨页推断。
- **双栏阅读顺序自动重建**：从版式几何独立恢复双栏顺序并与 OCR 流交叉验证。当前默认保留 OCR 物理顺序，只提供 `--reading-order geometry` 手动切换。
- **批量 Zotero 同步**：一次对多篇文献生成合并操作计划，并支持部分失败后的断点续跑。当前逐篇执行。
- **群组库写入实测**：群组库只读定位已实现并有测试，真实群组写入尚未在用户环境中验证。

## 中期

- **独立 Word（.docx）元数据与正文入口**：当前 Word 需先转 PDF；没有直接读取 docx 属性、批注或域代码的路径。
- **作者结构无损往返**：`authors` 与 Zotero `creators` 双向同步需要保存 creator 类型和姓名拆分；目前只比较，不回写。
- **Zotero 文献关系映射**：把 `has_supplement` / `supplement_to` 写入 Zotero `relations`。当前仅存在于 Obsidian frontmatter。
- **PDF 矢量图完整独立提取**：把单幅矢量图作为可缩放 SVG 提取，而不是页面渲染裁切。当前仅在单张位图可完整复原时走原生提取。
- **PPTX 组合对象与变换保真**：组合内图片、裁剪/旋转图片的原生恢复。当前保守回退为 PDF 裁切。
- **跨页脚注与边注归属**：把跨页断开的脚注自动还给原段落。当前保留脚注文本，但归属仍需人工核对。

## 远期

- **其他科研类型模板**：会议论文、预印本、技术报告、标准、专利、实验规程各有独立字段与结构规则，目前仅有期刊论文与学位论文的通用路径。
- **多文档知识网络**：跨论文的引用、方法与数据集关系图谱。当前只做单篇交付与主文/SI 双链。
- **Obsidian 客户端自动验收**：用可重复脚本核验阅读视图与实时预览的真实渲染，替代人工检查。当前沙箱只覆盖 KaTeX 与资源加载。
- **交互式图表修复 UI**：在浏览器中框选、预览、确认合图与拆图。当前依赖 JSON 修复草稿与命令行。
