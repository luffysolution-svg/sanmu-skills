# 主题路由与分层读取

用于反复查询已有教材、课件、论文或 SI 解析稿。一次性短问答直接定位原文即可；需要持续复用时才建立索引。工具不联网、不调用模型，不改写来源，也不自动生成摘要或科学结论。

## 建立可追溯入口

从技能目录运行，`--files` 只列相对来源根目录的 Markdown；输出使用新的独立目录：

```bash
python scripts/topic_tools.py build --root ./sources --files textbook.md paper.md paper-SI.md --out ./work/topics
python scripts/topic_tools.py query ./work/topics --root ./sources --query "一级反应半衰期与初始浓度有关吗" --limit 5
python scripts/topic_tools.py query ./work/topics --root ./sources --query "微调是否冻结基础模型" --terms Adapter 微调 --limit 5
python scripts/topic_tools.py read ./work/topics --root ./sources --id "<query 返回的块 ID>"
```

已有 sanmu-doc2md `agent/` 时，构建命令增加 `--agent-index ./sources/agent`，核对源行后复用分块与页码；工具不验证页码所指的 PDF 内容，引用前仍需回源核对。未提供时从 Markdown 建块，只给真实行号，不推定 PDF 页码。没有该技能也能独立使用。

`00-主题路由.md` 提供章节入口；查询返回候选片段和原文定位。中文与英文采用轻量词法匹配，分数不是证据强度，未命中不代表资料不存在。首次查询不足时，用原文术语、同义词或明确关键词重查，并记录查询扩展；不要靠不断增加候选数掩盖定位问题。

## 阅读升级与摘要

1. 从问题和主题入口选择章节，用候选片段判断相关性。
2. 可读已有章节摘要理解框架，但保留其身份：作者原文、导读、解读笔记分别记录。
3. 用 `read` 获取完整原文块，精确数值、公式、条件、机理和分歧回到结果、方法与 SI；图像内容仍须查看原图。
4. 上下文不足时继续读相邻块或完整小节，不用截断片段推断否定结论。超长公式与表格宁可整块读取。
5. 每次查询与读块核对来源哈希；来源改变后重建索引、重读相关证据，并复核摘要，不只更新哈希。

用户要求摘要、学习入口或方法卡时，由助手阅读后另存，不能把标题列表称为摘要。摘要保留来源路径、块 ID／行号、源哈希、适用条件与未读范围；按内容复杂度分配篇幅，不设置会丢失条件的统一压缩额度。参考入口侧重概念、公式、适用条件和回源；学习入口增加先修知识、已核验例题、易错点与自测。原题与新编题分别标记。

方法卡复用现有跨学科迁移字段，补充问题、输入、步骤、失败信号和验证例子；未验证的迁移保留假设状态，不自动注册为新 Skill。多来源冲突并列保留依据与条件，不因主题相同而覆盖旧结论。

## 实际问答验证

用同一来源集依次测试事实定位、同义表达、计算条件不足和主文／SI／解读身份区分。每题保留问题、查询及扩展词、返回块、实际读取范围、回答、短引文和回源判断；答案正确性由阅读核验，不由匹配分数决定。

分别记录：是否找到目标证据、是否支持回答、条件与单位是否保留、是否正确承认缺失信息。比较旧入口与新入口时保持来源和问题一致；可记录实际返回字符数及工具轨迹，只有取得宿主 token 用量才能报告 token 节省。合成测试、离线工具检查与真实问答分别说明，不能互相替代。
