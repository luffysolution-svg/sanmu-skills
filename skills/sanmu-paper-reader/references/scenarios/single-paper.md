# 单篇文献解读

## 适用与加载
- 用于解释一篇论文的研究问题、方法、结果、贡献与局限。
- 主文与其 SI 属于同一篇研究的证据包，不另算跨文献。
- 本文件作为主场景，仅按问题补读 1–3 个领域文件。
- 合成路线优先配合成表征；反应评价配催化电化学；理论论证配 DFT。
- 光谱归属和机理验证配光谱机理；排行榜或基准结论配性能比较。
- 不为覆盖目录而加载所有文件，不依赖其他研究技能。

## 操作步骤
1. 确认题名、版本、来源 ID、主文和 SI 的可读范围。
2. 用一句话确定论文试图回答的问题，注明作者是否明确提出。
3. 提取基线：已有方法的限制、比较对象和目标评价量。
4. 重建研究链：材料制备 → 结构证据 → 测试条件 → 结果 → 解释。
5. 围绕用户关心的主张精读对应方法、结果、图表及可获得的 SI。
6. 将主张逐条连接到已读证据，区分实测、计算与作者推断。
7. 检查对照、重复、误差与替代解释，再判断结论的适用范围。
8. 输出问题、证据链、贡献、局限和可执行的后续验证。

## 具体抽取字段
- 身份：来源 ID、题名、年份、版本、主文/SI 的对应关系。
- 范围：已读章节或页、可读图表、缺失附件、无法辨认的内容。
- 研究问题：研究对象、自变量、响应量、预期解决的限制。
- 材料：组成、相、形貌、负载、载体、样品编码和对照样品。
- 方法：关键制备条件、测量方式、计算模型、原位或非原位状态。
- 结果：数值、单位、误差、重复次数、归一化基准、测试条件。
- 关键主张：作者原意、支持证据、反证或替代解释、证据缺口。
- 创新边界：相对哪类已有对象、改进哪项量、是否仅为作者自述。
- 复现要件：必要参数、数据处理、校准信息及缺项状态。
- 局限：样品代表性、检测限、模型简化、工况和时间范围。

## 证据与引用
- 用来源 ID 稳定标识论文，例如 P01；补充材料标为同一 ID 的 SI。
- 引用格式：`[P01｜主文｜已读 Results“结构表征”节；Fig. 2b]`。
- SI 示例：`[P01｜SI｜已读“气相色谱校准”节；Fig. S4]`。
- 上述格式仅是模板，实际节名、图号必须来自已读原件。
- 页码仅在真实定位后填写，并区分 PDF 页序与印刷页码。
- 无页码映射时用已读章节或图表定位；不得估计或补造页码。
- 摘要中的主张只支持摘要层面的转述，不代表已核对完整证据。
- 未读到的 SI、参考文献和原始数据不得写成已核实来源。

## 判断边界
- 区分“观测到某信号”“信号支持某结构”“证明唯一机理”。
- 新材料与性能提高同时出现，只能先建立关联，不能自动确立因果。
- 单次测试、最佳样品与平均性能分别记录，不互相替代。
- 计算可支持解释；其模型适用性和与实验的一致性需要另行检查。
- 已读正文未找到的信息标“未报告（已读范围：…）”；未取得 SI/附件标“未获取”，可用但没读标“尚未阅读”，不能辨认标“无法辨认”。
- 仅在明确不涉及该方法或变量时标“不适用”；适用性未知标“待确认”。
- 作者宣称的首次、领先和普适性，没有独立比较时保留为作者主张。
- 证据不足时收窄结论，并指出最能区分解释的下一项验证。

## 建议输出
- 先回答用户问题，再给研究链和关键证据，最后说明局限。
- 关键结果可用“主张｜条件与数值｜证据定位｜支持程度”四列表。
- 支持程度写成可理解的判断，如“直接测量”“间接支持”“尚待验证”。
- 不强行填满模板；无关领域项目可省略，关键缺项保留。

## 按任务启用的增强功能

先确定用户的问题和交付范围；下列功能按需选择，不要求每次全部生成。科学主张的证据、数值单位、工况和来源仍需保留。

### 1. 图文对照证据链预览（Callout 展开 + 双链悬停）
需要图表对照且宿主支持时，采用“折叠抽屉 + 双链悬停”的复合对照模式：
- **双链悬停快捷预览**：在小节标题或正文中引用图表时，标注指向原文图块的锚点或链接（如 `[[Yang 等 - 2024#^fig1|Figure 1b ↗]]`），在启用页面预览的 Obsidian 中可悬停查看原图；其他宿主提供普通可用链接；
- **折叠抽屉深入对照**：在详细分析要点后，附上可折叠 Callout，默认折叠不占篇幅，点击展开大图与核心看点说明：
  ```markdown
  > [!example]- 📷 点击展开对照图表：Figure 1（XRD 演变与微观缺陷）
  > ![Figure 1|650](images/.../fig1.png)
  > *图注提示：重点观察 (b) 面板 400℃ 退火的 Ni/NiO 双重峰，与 (e) 面板 HAADF-STEM 圈出的晶界空位。*
  ```

### 2. 复现准备 SOP 草案与关键配方卡
用户需要复现准备时，将已读正文与 SI 的步骤整理成待实验人员审阅的草案。每个参数保留来源；缺失、未读与无法辨认项明确标注，不以经验值补齐，不称为可直接执行的规程：
- **前驱体与溶剂**：原料化学式、纯度、精确质量（g/mg）、摩尔比与溶剂体积（mL）；
- **反应与后处理程序**：溶胶-凝胶温度、干燥时间、气氛（Ar/N₂/Air）、升温速率（℃/min）与退火平台；
- **组装与分散**：载体比例、超声时长、溶剂体系、研磨/干燥条件；
- **反应评价工况**：催化剂投加量、反应液配比（牺牲剂 vol%）、光源功率（W）、滤波片（AM 1.5/波长截断）、控温状态；
- **已知复现缺口与安全预警**：注明原文未公开的关键工艺（如退火降温速率、密封漏气率校准）及易燃/挥发化学品处理要点。

### 3. Mermaid 反应机理与动力学流程图
需要流程图辅助解释时，将电荷转移、表面反应与能级匹配转化为原生的 Mermaid 流程图。
- 遵循 Mermaid 渲染规范（不含带引号的字体配置，节点标签避免不合法字符）；
- **连线文本防错规范**：连线标签（`-->|...|`）若含英文圆括号 `()`、冒号 `:`、斜杠或特殊符号，必须加双引号（如 `-->|"文本 (含参数)"|`），严禁裸括号导致解析器报 `got 'PS'` 语法崩溃；拆解多节点 `&` 连线为单边连线以减少兼容问题；在目标宿主验证渲染，未验证时说明；
- 以已读证据区分作者提出的路径、直接观测与待验证推断；示意图不代替验证实验。可按实际研究表达：`光激发 → 载流子分离与迁移 → 助催化剂界面捕获 → 表面催化反应 / 反应物吸附与脱附`。

### 4. SI 定向检索与附图/整页预览
需要补充材料时，可对有文字层的 SI 使用离线索引；扫描件先配置 OCR，不保证题注和参数完整召回：
```bash
# 文本与参数定向探测
python scripts/si_probe.py ./path/to/paper-SI.pdf --search "TEOA,xenon,Hubbard"

# 根据题注提取嵌入位图或渲染整页预览
python scripts/extract_si_figures.py ./path/to/paper-SI.pdf --out-dir ./images/SI
```
用候选结果定位合成试剂、电解液、校准和性能对比表，再回原页核对。图像清单的 `extraction_mode` 为 `embedded_image` 或 `page_render`；多图、组合位图和矢量内容优先整页渲染，同页图号共享页面文件，不声称独立图全量分离。裁切须检查面板边界、坐标与图例。

### 5. 子图精准切片（Sub-figure Crop）
多子面板复合大图（如 Figure 1 包含 a-i）可在解读具体分节时进行精准切片隔离：
```bash
python scripts/crop_subfigures.py ./images/master_fig.png --out-dir ./images/subfigures --spec-json ./crops.json
```
看哪一段分析就放哪一张小图（如 3.1 节放 Figure 1b XRD 单图，3.2 节放 Figure 1e 球差电镜单图），视觉焦点不分散。

### 6. Benchmark 结构化入库与 Zotero 学术标签增强
- **基准入库**：任务需要且获授权时，将带单位、工况与来源的性能写入 `benchmarks.csv`。用唯一 `record_id` 或 DOI/引用键 + `condition_id` 区分工况；仅更新显式字段，空字符串或 JSON null 可清空。旧格式唯一且无标识的行可按论文更新；含糊匹配按报错候选补标识，不自动合并或重写用户历史数据；
- **Zotero 学术标签**：用户授权此写入后，根据已核对的体系与反应，为文献打上结构化学术标签（如 `#光催化/产氢`, `#助催化剂/Ni-NiOx`, `#机理/FLPs`, `#AQY/40.8%`），增强知识库检索能力。

## 材料化学短例
- 假设论文报告缺陷 TiO₂ 的析氢增强，先提取缺陷表征及照射条件。
- 若只有 EPR 信号和析氢速率同步变化，可写“与缺陷增加相关”。
- 若缺少吸收光子数与温度对照，不能归因为本征量子效率提高。
- 引用已读的结构图和产气测试节；未读 SI 中的校准内容标未核实。
- 后续优先建议温度匹配对照及量子效率测量，并注明这是分析建议。
